# Birthday Surprise for Gauri 🎂✨

A dreamy midnight birthday website. Plain HTML, CSS and JavaScript — no server, no login, no paid tools.

```
birthday-surprise/
    index.html   (the page)
    style.css    (the look)
    script.js    (the animations and behaviour)
    README.md    (this guide)
```

---

## Part A — Set up the project (Windows + VS Code)

1. Install VS Code from https://code.visualstudio.com if you don't have it.
2. Create a folder on your Desktop named `birthday-surprise`.
3. In VS Code: **File → Open Folder…** and choose that folder.
4. Create the files: in the left panel, click the **New File** icon and make `index.html`, `style.css`, `script.js` (and `README.md` if you like).
5. Open each file and paste in the matching code, then press **Ctrl + S** to save.
   - Tip: if you downloaded the files from Claude, just copy them into the folder instead.

## Part B — Test it on your computer

Easiest: double-click `index.html` and it opens in your browser.

Better: in VS Code open the Extensions panel (Ctrl+Shift+X), install **Live Server**, then right-click `index.html` → **Open with Live Server**.

Check these:
- Type `Gauri` (try `  gAuRi  ` too) → the surprise unlocks. Press **Enter** to submit as well.
- Type a wrong name → you see the gentle "try again" message.
- Tap **Music off** (bottom right) → soft birthday tune plays. Tap again → it stops.
- Tap through: Continue → Gift → Letter → envelope → Make a Wish.

## Part C — Publish for free with GitHub Pages

1. Go to https://github.com and click **Sign up** (free). Verify your email.
   - Your username appears in the final link (`https://USERNAME.github.io/...`). If you'd rather not show your real name, choose a neutral username.
2. Click the **+** (top right) → **New repository**.
3. Repository name: choose something not easy to guess, like `midnight-sky-7391`. Set it to **Public** (required for free GitHub Pages). Click **Create repository**.
4. On the new page click **uploading an existing file**.
5. Drag `index.html`, `style.css` and `script.js` from your folder into the page (drag the files, not the folder). Wait for them to finish uploading.
6. Click **Commit changes**.
7. Go to **Settings → Pages** (left menu).
8. Under **Build and deployment → Source**, choose **Deploy from a branch**. Under **Branch** choose **main** and **/ (root)**, then **Save**.
9. Wait 1–3 minutes and refresh the Pages settings page. A box appears saying **"Your site is live at …"**. That `https://…github.io/…` address is your real link — it only exists after you publish; copy it from there.

## Part D — Test on your phone, then send it

1. Send the link to yourself (WhatsApp "Message yourself" works) and open it on your phone.
2. Do the full run-through once: name → birthday → gift → letter → wish → music.
3. If something looks old after an update, refresh the page or open it in a private tab (the site can take a minute to update after you change files).
4. At 12:00 AM, paste the link into WhatsApp and send it to Gauri. WhatsApp has no built-in scheduling, so set a phone alarm for a few minutes before midnight. Add a short line like "Open this at midnight ✨" if you like.

## Customising

- **Letter text:** edit the paragraphs inside `<article id="letter">` in `index.html`. Change "Your friend 💜" to your name if you want it signed.
- **Your own music:** put an MP3 you have the right to use in the folder (e.g. `music.mp3`), upload it to GitHub too, and in `script.js` set `musicFile: 'music.mp3'`. By default the site plays a built-in music-box tune generated by the browser, so no audio file is needed.
- **Accepted names:** edit `acceptedNames` at the top of `script.js` (lowercase), e.g. `['gauri', 'gouri']`.

## Notes

- The name check is just a playful gate. Anyone with the link can look at the code, so don't treat it as security.
- Nothing is collected, stored or sent anywhere.
- Animations are reduced automatically for people who have "reduce motion" turned on.
- The page has `noindex` so search engines are asked not to list it.
